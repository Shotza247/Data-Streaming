# 🚀 Open-Source Real-Time Streaming Analytics Platform

A fully containerized, end-to-end real-time data streaming and AI analytics platform built entirely with open-source technologies.

This project demonstrates how modern data engineering, machine learning, vector search, data lineage, and AI agents can be integrated into a single production-style architecture.

The platform simulates a tax analytics environment where events are generated, streamed through Kafka, processed with Flink SQL, stored across multiple data layers, enriched with machine learning, and exposed through AI-powered agents and dashboards.

# 🎯 Project Goals
This platform was built to explore and demonstrate:
1. Real-time event streaming
2. Stream processing with SQL
3. Data lakehouse principles
4. Feature engineering and ML workflows
5. Vector search and semantic retrieval
6. AI agent orchestration
7. Data lineage and observability
8. Production-style containerized deployments

# ⚡ Quick Start
1. Clone the Repository
git clone <repo-url>

cd data-streaming

2. Start Podman
podman machine start

3. Launch the Platform
make up

4. Deploy Flink SQL Jobs
make submit-sql

5. Populate Vector Database
make seed

6. Validate the Platform
make smoke-test

7. Open the Dashboard
http://localhost:8501

# 📊 Data Flow
Tax events are generated by Kafka producers.
Kafka topics receive incoming events.
Flink SQL processes and enriches records.
Results are distributed across Postgres, Redis, MinIO, and Qdrant.
OpenLineage emits metadata to Marquez.
DuckDB performs analytics against processed datasets.
MLflow trains and tracks machine learning models.
LangGraph agents consume models and vector search results.
Streamlit visualizes operational metrics and AI insights.
